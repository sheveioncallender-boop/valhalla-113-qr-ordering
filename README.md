# Valhalla 113 QR Table Ordering

Odoo 19 addon **19.0.1.1.0**, deployed from `main` through Cloudpepper.

Extends native Odoo POS self-ordering with Valhalla branding and printable table QR cards. Preserves native table, payment and preparation flows. Includes separate initial setup and branding-only actions.
