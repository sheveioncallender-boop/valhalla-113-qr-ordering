A focused Odoo 19 addon that extends the native Restaurant POS and Self Order flow with branded, printable table QR cards and dependable floor-plan table assignment.

SCAN

Generate a secure native Odoo self-order link for every selected table.

ORDER

Guests browse the POS menu and submit from their own mobile device.

CHARGE

The draft order reaches the matching restaurant table for staff payment.

Built on Odoo's native restaurant engine

  • Restaurant floors and table layout remain native.
  • QR URLs use Odoo's POS access token and table identifier.
  • Self-order pricing and order validation remain server controlled.
  • Orders retain both self-order and floor-plan table references.
  • Four-card A4 and one-card-per-page PDF layouts are included.
  • Table labels, QR eligibility and print history are manageable.
